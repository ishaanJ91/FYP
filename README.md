# NDN Dissertation Notes

Reading notes for my final-year dissertation at Trinity College Dublin on AI agents and Named Data Networking (NDN). The project is building towards a Model Context Protocol (MCP) server that lets an AI agent diagnose NDN networks. This repository collects the papers I've read, most of them on NDN dataset synchronisation, pub/sub over NDN, prior NDN dissertations and MCP, together with my notes on each one.
